# 搭子屋 合租生活管家

一个面向年轻合租群体的静态网页 Demo。核心流程覆盖共同费用、家务轮值、用品采购、成员规则与本地数据管理。

## 当前能力

- 今天：聚合当前成员的家务、采购、待付款和规则确认事项；结算任务会按室友聚合。
- 费用：月份切换、四种分摊方式、整数分计算、结算分配、部分结算、成员付款进度和结算历史。
- 家务：自然周与日期筛选、逾期派生、指定转交、跳过本轮、周期任务自动生成下一轮。
- 用品：库存量与进度、已用完状态、唯一认领、手动校准、采购自动入库和自动生成共同费用。
- 更多：Demo 多身份切换、成员与管理员管理、规则新版本、事件通知、JSON 导入导出和崩溃恢复。

## 本地运行

使用任意静态服务器打开 `dist` 目录。应用使用 Hash 路由和相对资源路径，兼容 GitHub Pages 子路径。

## 数据

业务数据保存在浏览器 `localStorage` 的 `hezu-life-manager:v3:state`。首次打开会自动迁移 v2 数据及更早的费用、家务、用品记录，并保留迁移前备份。v3 新增结算分配、家务模板、库存流水、规则版本和采购时间字段。

## 测试

```bash
node --test tests/domain.test.mjs tests/store.test.mjs
```

## 已知边界

当前版本是单设备作品集 Demo，不包含真实账号、云端多人同步、系统推送或支付能力。
